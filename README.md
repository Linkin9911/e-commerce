# E‑commerce Core
Ядро интернет‑магазина на Python с использованием объектно-ориентированного программирования (ООП). Проект реализует основные сущности и бизнес‑логику для управления товарами, категориями и заказами, демонстрируя работу с абстрактными классами, миксинами и строгой типизацией.

# Реализованная функциональность
В рамках проекта реализованы следующие ключевые компоненты:

Абстрактный базовый класс BaseProduct:

Является родительским для класса Product.

Содержит общую функциональность, обязательную для всех продуктов.

Использует механизмы ABC и декоратор @abstractmethod для определения обязательных к реализации методов.

* Класс Product:

Наследуется от BaseProduct и миксина LoggingMixin.

Инкапсуляция данных: приватные атрибуты цены и количества с защищенными геттерами и сеттерами.

Валидация данных: проверка на пустые названия, отрицательные цены и недопустимое количество (≤ 0).

Класс‑метод new_product() для создания или обновления продукта из словаря.

Перегрузка оператора __add__() для агрегации двух товаров (расчет средней цены и суммарного количества).

* Класс‑миксин LoggingMixin:

Автоматически логирует создание объекта в консоль, выводя имя класса и параметры инициализации (например: Product('Продукт1', 'Описание', 1200, 10)).

Внедрен в цепочку наследования класса Product через множественное наследование.

* Специализированные классы:

Smartphone: наследуется от Product, имеет специфические атрибуты (модель, память, цвет, производительность).

LawnGrass: наследуется от Product, имеет атрибуты для категории товаров для сада (страна‑производитель, срок прорастания, цвет).

* Управление категориями и заказами:

Category: группировка товаров, расчет средней цены в категории, поддержка итерации по товарам.

Order: создание заказа с валидацией наличия товара на складе и расчетом итоговой стоимости.

* Работа с данными:

Загрузка данных из JSON-файла с обработкой ошибок (JSONDecodeError, FileNotFoundError).

Корректная обработка крайних случаев и исключений.

* Тестирование и качество кода:

Покрытие кода тестами — более 75%.

Статическая проверка типов с помощью mypy.

Проверка стиля кода согласно PEP 8 с помощью flake8.

Отчёт о покрытии доступен в папке htmlcov/index.html.

# Загрузка данных из JSON
Метод load_data_from_json возвращает объект Category, заполненный товарами согласно типу (product_type в JSON).

python
from src.main import Category

try:
    category = Category.load_data_from_json("data.json")
    print(f"Загружена категория: {category.name}")
    
    for product in category:
        print(f"- {product.name}: {product.price} руб.")
        
        # Доступ к специфичным атрибутам через проверку типа
        if isinstance(product, Smartphone):
            print(f"  -> Тип: Смартфон, Модель: {product.model}")
        elif isinstance(product, LawnGrass):
            print(f"  -> Тип: Трава, Страна: {product.country}")
            
except FileNotFoundError:
    print("Файл data.json не найден.")
except Exception as e:
    print(f"Произошла ошибка при загрузке: {e}")
