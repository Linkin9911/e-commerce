# E‑commerce Core

Ядро интернет‑магазина на Python с использованием ООП. Проект реализует основные сущности и бизнес‑логику для управления товарами и категориями, включая абстрактные классы и миксины.

## Реализованная функциональность

В рамках текущего задания реализованы следующие ключевые улучшения:

* **Абстрактный базовый класс `BaseProduct`**:
    * является родительским для класса `Product`;
    * содержит общую функциональность, обязательную для всех продуктов;
    * использует механизмы `ABC` и `@abstractmethod` для определения обязательных методов.

* **Класс `Product`**:
    * наследуется от `BaseProduct` и миксина `LoggingMixin`;
    * приватный атрибут цены с геттером и сеттером;
    * валидация цены (не может быть нулевой или отрицательной);
    * запрос подтверждения при снижении цены;
    * класс‑метод `new_product()` для создания или обновления продукта из словаря;
    * метод `__add__()` для расчёта общей стоимости двух продуктов.

* **Класс‑миксин `LoggingMixin`**:
    * при создании объекта выводит в консоль информацию о классе и параметрах создания (например: `Product('Продукт1', 'Описание продукта', 1200, 10)`);
    * добавлен в цепочку наследования класса `Product`.

* **Специализированные классы**:
    * `Smartphone` — наследуется от `Product`, имеет атрибуты: модель, память, цвет, производительность;
    * `LawnGrass` — наследуется от `Product`, имеет атрибуты: страна‑производитель, срок прорастания, цвет.

* **Тестирование**:
    * написаны тесты для новой функциональности (абстрактный класс, миксин);
    * покрытие кода тестами — более 75 %;
    * отчёт о покрытии доступен в папке `htmlcov/index.html`.

* дополнительные возможности:
    * загрузка данных из JSON с обработкой ошибок;
    * обработка крайних случаев (пустые названия, отрицательные цены и т. д.).

# Критерии приёмки
