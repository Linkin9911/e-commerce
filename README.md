# E‑commerce Core

Ядро интернет‑магазина на Python с использованием ООП. Проект реализует основные сущности и бизнес‑логику для управления товарами и категориями.

## Функционал

* **Класс `Product`**:
  * приватный атрибут цены с геттером и сеттером;
  * проверка корректности цены (не может быть нулевой или отрицательной);
  * запрос подтверждения при снижении цены;
  * класс‑метод `new_product()` для создания/обновления продукта из словаря;
  * метод `__add__()` для расчёта общей стоимости двух продуктов.
* **Класс `Category`**:
  * приватный список товаров;
  * метод `add_product()` с проверкой типа добавляемого объекта;
  * геттер `products` для форматированного вывода списка;
  * итератор для удобного перебора товаров;
  * автоматическое отслеживание количества категорий (`category_count`) и товаров (`product_count`).
* **Специализированные классы**:
  * `Smartphone` (модель, память, цвет, производительность);
  * `LawnGrass` (страна‑производитель, срок прорастания, цвет).
* Загрузка данных из JSON с обработкой ошибок.
* Обработка крайних случаев (пустые названия, отрицательные цены и т. д.).

## Использование
Базовое использование
python

# Создание товаров
product1 = Product("Смартфон", "Современный смартфон", 29999.99, 10)
product2 = Product("Ноутбук", "Мощный ноутбук", 59999.99, 5)

# Создание категории и добавление товаров
category = Category("Электроника", "Электронные устройства")
category.add_product(product1)
category.add_product(product2)

# Вывод списка товаров в категории
print(category.products)
Создание товара через класс‑метод
python
product_data = {
    "name": "Планшет",
    "description": "10-дюймовый планшет",
    "price": 35000.0,
    "quantity": 7
}
new_product = Product.new_product(product_data)
Специализированные классы
