# E-commerce Core

Ядро интернет‑магазина на Python с использованием ООП.

## Функционал

- Класс `Product` с атрибутами: название, описание, цена, количество.
- Класс `Category` с атрибутами: название, описание, список товаров.
- Автоматическое отслеживание количества категорий и товаров.
- Загрузка данных из JSON.

## Запуск

1. Установите зависимости: `poetry install`.
2. Запустите тесты: `poetry run pytest --cov=src`.
3. Проверьте стиль кода: `poetry run flake8`.
